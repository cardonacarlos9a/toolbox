# Privacy policy

The projects in this repository are personal tools used only by their owner (cardonacarlos9a@gmail.com).

- **drive-docs-mcp** uses Google sign-in to read and edit text files in one Google Drive folder chosen by the owner. It acts only on that folder, only when the owner's Claude connector calls it.
- File contents are not stored, sold or shared. The server logs only the name of each operation and the file path.
- The Google refresh token is kept in the hosting provider's encrypted environment settings. It can be revoked at any time at https://myaccount.google.com/permissions.
